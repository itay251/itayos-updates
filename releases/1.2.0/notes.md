# ITAYOS 1.2.0

עדכונים לשתי התוכנות דרך GitHub, בלי להקים שרת ובלי להגדיר מפתחות אצל המשתמשים.

## מה חדש

- שתי הגרסאות מחוברות מראש למקור העדכונים המשותף. לאחר התקנת 1.2.0 פעם אחת, אפשר לבדוק ולהוריד עדכונים מתוך התוכנה.
- למנהל התוכנה יש מתקין אישי עם מסך פרסום. פרסום מחייב אישור של חשבון GitHub של מנהל התוכנה; למשתמשים ולמודים אין הרשאת פרסום.
- מסך הניהול מציג תיאורי עדכון שהוכנו מראש וגרסאות שמוכנות לפרסום. אפשר גם לבחור שני מתקינים תואמים מהמחשב.
- שני המתקינים נבדקים לפני פרסום, והלקוחות בודקים SHA-256 לפני התקנת עדכון.
- אפשר לבדוק עדכונים גם מתפריט ITAYOS Mod, ללא תלות בחיבור לערוץ.
- נשמרו הפעלה עם Windows, פתיחה בחלון מוגדל ולא במסך מלא, והמשך פעולה ברקע בעת סגירת החלון.
- הסמל הראשי ירוק, והסמל של ITAYOS Mod כחול.

## בחירת מתקין

- `ITAYOS.Setup.1.2.0.exe`: תוכנת ITAYOS הרגילה למשתמשים.
- `ITAYOS.Mod.Setup.1.2.0.exe`: תוכנת ITAYOS Mod.
- `latest.json`: מידע טכני לבדיקת העדכונים; אין צורך להוריד אותו ידנית.

מתקין הניהול האישי אינו מופץ בעמוד הציבורי הזה. המתקינים מיועדים ל-Windows ‏64 ביט ואינם חתומים בתעודת Authenticode.
